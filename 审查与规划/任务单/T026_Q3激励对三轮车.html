为什么：T025 证明的是“激励换不掉卡车”——而 Q2 的卡车层是 50 区级，区级日基线未服务只有 432.23 辆，本来就没有可替代的空间，所以那个负结论是结构性的，不是激励本身的问题。激励真正替代的是格级短缺；现在格级短缺由三轮车处理（T024-R3）：239,245.20 → 39,984.23，三轮车层成本 293,342.61 元/日，折 1.47215 元/未服务辆。把奖励和这个单价放在一起，方向就反过来了。

这只是上界，不能直接当结论，因为三处近似：① 1.47215 是平均成本（(固定+里程)/移除量），逐区不动点是整数，少填一点短缺不一定能减一辆车；② q(r) 是在 T008 的短缺 Δ_c 上算的，不是 T024 动态回放的格级短缺；③ 卡车层在 r 变化时应保持不变，需要验证。本任务就是把这三条做实。

2. 要做什么

  1. 统一短缺口径：用 T024 的（格, 小时）短缺作为 Δ_c，重建 T008 的 reroute LP（同一接受函数 π(r)，κ/ρ/c0 不变，两种来源上限），得到 q(r) 与实际填掉的短缺。Δ_c 只取“步行之后仍然缺”的那部分，必须与 T024 的 cellunmet 口径对齐，写清对齐方式。
  2. 外循环：给定 r，(a) 在剩余短缺上跑 reroute LP；(b) 把剩余短缺送回 T024 的逐区三轮车 LP 与逐区不动点，求 n_z(r)；(c) 迭代到不动点（最多 10 次，残差 < 1 辆）。报告每行的迭代次数与末次残差。
  3. r 扫描：r ∈ {0, 0.05, 0.10, …, 3.00}（61 档；2026-11-18 从 2.00 扩到 3.00，见 §5 H26），两种来源上限各一遍。每档报告 total(r) = payment + 三轮车层 + 卡车层（卡车层应不变，若变要解释），并报告 payment 是否被预算 30,000 截断。
  4. 复核 T020 的 r=0.81（H26）：单独报告 total(0.81) 与 total(2.7) 的对比（同预算、同来源上限），写清 r=2.7 的 payment 是否同样被 30,000 上限截断、卡车层是否更低、总支出哪边更低。若 2.7 更优，给出新的 r* 以及对论文 §6/摘要的影响。
  5. 回归门：r = 0 必须逐位复现 T024-R3：975 辆、617,055.7515、未服务 39,984.2332、未分配 0、层成本 533,248.0077。
  6. 求根与最优：给交叉点 r_cross（total(r) = total(0) 的根，二分到 0.001 元）、最优 r*、净节省、以及 n_z 的逐区下降（总下降多少辆、哪些区下降）。
  7. 与上界对照：把精确结果与第 1 节的上界画在同一张表里，说明差距来自整数化还是来源上限。
  8. 敏感性：接受函数 c0 ±20% 下 r* 与净节省的移动（各一行即可）。

  6. 复现信息（种子、命令、输入 SHA-256）；交付 JSON 按契约；单独 commit，不 push。

4. 口径与禁区

  • 不得写“可测量的移除”；写“在同一模型内，把奖励从 1.76 降到 r* 使总成本下降 X 元/日”。
  • 与 T025 不矛盾，要并列：T025 是卡车口径（区级无短缺，激励换不掉卡车）；T026 是格级/三轮车口径（激励可以替代三轮车）。论文两段都要写，并写清各自的适用条件。
  • 第 1 节的平均成本上界只能作对照，不能作结果；结果只用外循环的精确值。
  • 奖励支付是平台支出，三轮车成本也是平台支出，两者可比；用户的时间成本不计入（与 T008 一致），要在 assumptions 里写明。
  • 不得引用 T008 的 6.83%–20.83% 作系统节省，也不得引用 T025 的 10.40 / 2,883.3 / 480.6×。
